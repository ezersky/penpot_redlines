# Redlines: Spec Sheet — Penpot plugin

## Что делает

1. Выделите ровно один элемент в макете.
2. Настройте направление копии (справа/снизу от оригинала) и отступ.
3. Выберите, что включить: ширина/высота, отступы, промежутки, список аннотаций.
4. «Создать Spec Sheet» → плагин:
   - клонирует элемент через `shape.clone()` (полноценная копия, не SVG-роундтрип —
     сохраняются все свойства, включая связи с компонентами библиотеки);
   - размещает копию рядом с оригиналом;
   - обвешивает копию теми же замерами, что и в **Redlines: Measures** (ширина/высота,
     padding, gap — с сопоставлением значений с токенами файла: `16px (spacing/medium)`);
   - если у элемента уже есть аннотации из **Redlines: Annotations** (найденные по
     `ddx-target-id`), добавляет их текстовым списком под копией;
   - группирует копию и выноски в одну фигуру через `penpot.group()`.

## Файлы плагина

```
manifest.json   — метаданные и permissions (content:read, content:write, library:read)
plugin.js       — sandbox-скрипт: clone(), обход дерева, createShapeFromSvg, group()
index.html      — форма (направление/отступ/опции)
styles.css      — оформление в духе Penpot UI Kit (тот же язык, что и в прошлых плагинах)
ui.js           — позиционирование копии, замеры (портировано из Measures), генерация SVG
icon.png        — иконка 56×56
```

## Как это устроено внутри

- **Клонирование, а не пересборка через SVG.** В отличие от оверлеев (линии, бейджи), сам
  дубликат элемента создаётся через `shape.clone()` — это сохраняет полную структуру
  (вложенность, связи с библиотечными компонентами, стили), чего не даёт путь через
  `createShapeFromSvg`.
- **Переиспользование данных между модулями.** Spec Sheet не хранит ничего своего — он читает
  аннотации, оставленные модулем Annotations, по той же метке `ddx-target-id`, которую тот
  проставляет на бейджах. Уберите Annotations из связки — Spec Sheet продолжит работать, просто
  без списка аннотаций.
- **Координаты копии, не оригинала.** Все линии замеров и подписи строятся относительно новой
  позиции копии (`offsetX/offsetY`), а не оригинала — то есть выноски физически указывают на
  дубликат, который и предназначен для документации, оставляя исходный макет нетронутым.
- **plugin.js — единственное место с `penpot.group()`.** `ui.js` не может группировать фигуры
  напрямую (нет доступа к `penpot`), поэтому просто передаёт готовый SVG-оверлей и координаты;
  сама операция `clone()` → `createShapeFromSvg()` → `group()` происходит в sandbox за одно
  сообщение `create-spec`.

## Ограничения v1 (честно)

- Как и в Measures: только flex-раскладка (`shape.flex`), grid не читается.
- Клонируется **один** элемент за раз, не выборка из нескольких.
- Если исходный элемент содержит анимации/интерактивные состояния (несколько вариантов), клон
  — это статичный снимок текущего состояния на холсте, не все варианты сразу.
- Нет автообновления Spec Sheet при последующем изменении оригинала — это статичный снимок на
  момент создания, не живая связь. Пересоздание — повторный клик «Создать Spec Sheet» (создаст
  новую копию рядом, не обновит старую).

## Установка

Как и любой Penpot-плагин, `manifest.json` должен быть доступен по публичному URL:

1. [Netlify Drop](https://app.netlify.com/drop) — перетащите папку, допишите `/manifest.json`.
2. Локально: `npx serve .` или `python3 -m http.server 4400`.
3. В Penpot: `Ctrl+Alt+P` → «Plugin manager» → вставить URL `manifest.json` → «Install».

## Тестирование

Реального Penpot-файла в этой песочнице нет, поэтому:

- Позиционирование копии, портированная логика замеров, генерация SVG (заголовок + замеры +
  список аннотаций, с XSS-безопасным экранированием) — 24 проверки в Node без DOM.
- Полный UI-флоу (выбор цели → получение аннотаций/токенов → живое превью → переключение
  направления/опций без повторных запросов → создание → путь ошибки) — 25 проверок через
  DOM-шим.
- `plugin.js` — 18 проверок с фейковым `penpot`, включая `clone()`, `group()`, фильтрацию
  аннотаций по `ddx-target-id` (в том числе отсечение аннотаций, принадлежащих ДРУГИМ фигурам
  с тем же номером — не только "нашлась хоть какая-то запись"), и три отдельных пути отказа:
  фигура не найдена, `createShapeFromSvg` вернул `null`, фигура не поддерживает `clone()`.

```bash
cd test
node run_logic.js       # позиционирование, замеры, генерация SVG, без DOM
node simulate_flow.js   # полный UI-флоу через DOM-шим
node run_plugin.js      # plugin.js с фейковым penpot (clone, group, обход дерева)
```
